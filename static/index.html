Get a Groq API key (free)
  1. Open console.groq.com/keys and sign up.
  2. Create an API key (starts with gsk_) and copy it.
  3. In the project folder: copy .env.example to .env, paste the key as GROQ_API_KEY=….
  4. Restart the app (python app.py). The banner above disappears when the key loads.
